Notix Privacy Policy

Effective October 13, 2026

Notix is a Chrome extension for capturing a browser tab, recording click sequences, annotating them, and generating a text ready to paste into an artificial intelligence tool. This policy explains what information Notix processes and where it stays.

The essentials

  • Everything Notix processes stays on the user's computer. There are no Notix servers, accounts, or sign-ups.
  • Notix does not collect, send, sell, or share information with anyone.
  • Notix uses no analytics, cookies, or trackers.

What information Notix processes

Only what the user creates while using the extension:

  • Screenshots of the visible tab, taken when the user presses the shortcut or the capture button.
  • Data about the captured tab: its address (URL), the page title and, when recording a sequence, the screen heading and the text of the clicked element. They are used to name each capture and describe each step.
  • Comments, notes, and drawings the user adds on top of the captures.
  • Extension preferences, such as the selected tool or notices the user asked not to see again.

Where that information stays

  • In the browser's local storage, on the user's computer.
  • In the Downloads/Notix folder of the computer, as images and text files, when the user clicks "Copy prompt".
  • On the computer's clipboard, as text, at that same moment.

Notix does not transmit any of this to any server.

What the user decides

The text Notix copies is meant to be pasted into a third-party artificial intelligence tool, such as Claude Code. Pasting it is the user's decision, outside Notix, and is subject to that service's terms and privacy policy.

Screenshots show whatever was on screen, which may include personal information about the user or other people. Notix masks sensitive address parameters (such as tokens or passwords) in the prompt text, but does not alter the image. Reviewing what is captured and shared is the user's responsibility.

Permissions the extension requests and why

  • Active tab and tabs: capture the visible tab and read its address and title.
  • Website access (optional): only while recording a sequence, to detect clicks on the page. Chrome asks the first time and the user can decline.
  • Storage: keep captures, annotations, and preferences on the computer.
  • Downloads: write the images and the prompt into the Downloads/Notix folder.
  • Context menu: offer capturing from the right-click menu.

How to delete the information

  • Each capture or sequence can be deleted from the Notix list.
  • "Delete all captures", in Settings, empties the extension's storage.
  • Uninstalling the extension removes its local storage.
  • Files in Downloads/Notix are deleted like any other file on the computer.

Children

Notix is not directed at children under 13 and does not collect information from anyone, regardless of age.

Chrome Web Store policy compliance

Notix's use of information received from Chrome APIs adheres to the Chrome Web Store Developer Program Policies, including the Limited Use requirements.

Changes

If this policy changes, the new version is published at this same address with its effective date, and the extension notifies the change.
